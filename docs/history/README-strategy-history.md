# Archived strategy announcements

These are the announcements formerly stacked in the README. They describe different versions and evaluation scopes, not simultaneous current behavior. See [the current architecture](../CURRENT_ARCHITECTURE.md) and [v9 results](../evaluation/v9-arena-results.md).


The current policy is **v9: category playbooks**, integrating Ksu's negotiation strategy with the action/response memory on main. It tailors commercial concessions to strategic supply, capacity, quality and competitive RFQs; repairs jointly invalid opening terms before proposing alternatives; and reserves more time for final authorization. See [implementation and evaluation scope](../evaluation/v9-category-playbooks.md). Seven other cases with best scores below 0.7 are selected for one Arena session each; no improvement is claimed before those results exist. The earlier version notes below describe their historical evaluations.

`hollerau.analytical` uses `gpt-6-astra` for a negotiator and a separately prompted final decision-maker. The v8.3 controller gives Astra the last word on counters, questions, confirmation, acceptance and walking away, including after supplier agreement and near wave deadlines. Python cannot override that selection with its uncertain acceptance model.

Both roles receive consistent cost estimates, including relationship uncertainty. Astra can choose conditional payment/index/commitment packages, ask for cost walkthroughs and approval routes, and retrieve earlier same-supplier/case exchanges from SQLite. Historical quotes must be reconfirmed. Numeric evidence is rendered from verified facts. Qwen and model-free modes remain explicit comparisons. These mechanisms do not guarantee higher Arena scores.

V8.3 implements the independent audit's first structural intervention: historical buyer proposals become selectable alongside the supplier replies they preceded. Memory records the prior terms, supplier status and negotiation stage, so an old closing concession is not confused with the opening that produced it. Astra chooses whether that earlier move fits the current situation. Cost calculations, timeout settings and stopping rules are unchanged. Two Arena runs scored **P02 0.255 and P18 0.273, both unchanged**. The earlier P18 opening was available but not selected, and all three P18 proposer calls timed out. No local tests ran. See [the implementation](../evaluation/v83-action-response-memory.md) and [actual results](../evaluation/v83-arena-results.md).

V8 corrects false acceptance labels, records terminal walkouts, reconstructs behavioural learning, and enables Astra-authored supplier replies with exact fixed facts. It presents next-action gains, losses and final-offer evidence before the final choice, and gates sustainability concerns by the case objective. See [the v8 implementation](../evaluation/v8-decision-feedback.md). The two evaluation pairs scored P02 0.000 then 0.255, and P18 0.273 twice. Neither exceeded its previous best. V8.2 adds forecast and neutral cost-driver retrieval; it was included in the V8.3 pair but has not been evaluated separately. No local tests ran. See [all scores and the evidence-access diagnosis](../evaluation/v81-arena-results.md).

A subsequent authorized DeepSeek V4 Pro review identified prompt-size and timing concerns, but its proposed code failed source-level review: among other defects, its schema and validator disagreed on closing actions. No proposed runtime edits were applied. See [the external review and rejected changes](../evaluation/v83-deepseek-review.md).

V7 preserves original should-cost evidence, separates production-cost estimates from acceptance behaviour, and calibrates supplier economics using completed practice cost breakdowns. It includes higher-price sustainability alternatives and explicit downside comparisons. See [the implementation and assumptions](../evaluation/v7-supplier-economics.md). No local tests are run for this update.

V7's two hosted runs were mixed: **P02 improved to 0.255** (previous best 0.157), while **P18 scored 0** after Astra countered a final offer and the supplier walked away (previous best 0.340). P02's relationship-cost forecast error fell to €150 on the observed deal. See [the actual v7 results and remaining weaknesses](../evaluation/v7-arena-results.md), [the v6 P02 diagnosis](../evaluation/v6-p02-arena.md), and [the earlier hosted evaluation](../evaluation/v51-arena-results.md). Future strategy evaluations use **P02 and P18 in Arena only**, with local tests stopped.

See [setup, parameters and current decision flow](../ANALYTICAL.md), [initial five-session results](../evaluation/FIVE_PRACTICE.md), and [improved five-session comparison](../evaluation/IMPROVED_FIVE_PRACTICE.md). `play` and `run` default to `--brain analytical`; the legacy agents remain explicitly selectable. Use `tacto-bayes` for bounded practice. `local` retains its model-free default.

The implementation uses Entire's supported external-agent import to attach actual scoped Codex development records. Earlier unrelated history and credentials are excluded; original source-session IDs, timestamps and record hashes are preserved. See the provenance section of the setup guide. Commit trailers and remote checkpoint refs are verified after publishing.
